Leçon 8

Installation de Windows

Installer Windows 11 de manière méthodique : préparer le support, démarrer l’ordinateur ou la machine virtuelle, choisir le type d’installation, sélectionner correctement le disque, suivre Windows Setup et terminer la configuration initiale.

Objectifs d’apprentissage. À la fin de cette leçon, l’étudiant sera capable de préparer une installation de Windows 11, d’identifier les principales étapes de Windows Setup, de distinguer mise à niveau et installation personnalisée, de sélectionner prudemment le disque cible, de terminer l’expérience de première configuration (OOBE) et de vérifier qu’une installation est fonctionnelle.
Important : une installation personnalisée peut supprimer les partitions et les données du disque cible. Avant toute manipulation sur une machine réelle, sauvegardez les données importantes et vérifiez précisément le disque sélectionné.

1. Qu’est-ce qu’une installation de Windows ?

Définition

L’installation de Windows est le processus qui prépare un disque, applique les fichiers du système d’exploitation, configure le démarrage et initialise Windows afin qu’il puisse fonctionner sur l’ordinateur.

Dans une installation interactive, Windows Setup guide l’utilisateur à travers les choix nécessaires : langue, édition ou licence selon le média utilisé, type d’installation, disque cible et configuration initiale.

Exemple

Dans un laboratoire, Windows 11 peut être installé dans une machine virtuelle VirtualBox. Cette méthode permet de pratiquer les étapes d’installation sans modifier le système principal de l’ordinateur hôte.

Exercice 1. Expliquez pourquoi une machine virtuelle constitue un environnement approprié pour apprendre à installer Windows.

2. Préparer l’installation

Une installation fiable commence avant le démarrage de Windows Setup. Il faut vérifier le système à installer, la compatibilité de la machine, les données à conserver et le support d’installation.

ÉlémentVérification
Édition et architectureIdentifier la version de Windows 11 et l’architecture adaptée à la machine.
Configuration matérielleVérifier que la machine satisfait aux exigences du système.
DonnéesSauvegarder les fichiers importants avant toute modification du disque.
StockageIdentifier le disque cible, sa capacité, ses partitions et l’espace disponible.
SupportPréparer une clé USB amorçable ou une image ISO dans une VM.
AlimentationÉviter une interruption pendant l’installation.
Lien avec les leçons précédentes : la préparation du support, le mode UEFI, le partitionnement et la création d’une VM ont déjà été introduits. Ici, l’objectif est de les mobiliser pour réaliser l’installation de Windows.

3. Obtenir le support d’installation officiel

Pour Windows 11, utilisez la page officielle de Microsoft. Elle propose notamment l’Assistant d’installation, la création d’un support et le téléchargement d’une image ISO selon les options disponibles au moment du téléchargement.

Page officielle : Télécharger Windows 11 — Microsoft

Sur une machine physique

Pour une installation depuis le démarrage, le support doit être amorçable. Une clé USB préparée avec l’outil approprié contient les fichiers nécessaires et les informations permettant au firmware de lancer Windows Setup.

Dans une machine virtuelle

Il n’est généralement pas nécessaire de créer une clé USB physique. L’image ISO peut être associée au lecteur optique virtuel de la VM, puis utilisée comme support de démarrage.

Exercice 3. Quelle différence existe entre l’utilisation d’une image ISO dans VirtualBox et l’installation de Windows sur une machine physique à partir d’une clé USB ?

4. Démarrer sur le support d’installation

Pour lancer une nouvelle installation, l’ordinateur doit démarrer sur le support contenant Windows Setup plutôt que sur le système déjà présent sur le disque.

Machine physique

  1. Connecter le support USB amorçable.
  2. Redémarrer l’ordinateur.
  3. Ouvrir le menu de démarrage temporaire ou configurer l’ordre de démarrage dans UEFI.
  4. Sélectionner le support d’installation.
  5. Vérifier que Windows Setup apparaît.

Machine virtuelle

  1. Associer l’image ISO à la VM.
  2. Vérifier l’ordre de démarrage virtuel.
  3. Démarrer la VM.
  4. Vérifier que l’installateur Windows se lance depuis l’ISO.

5. Premier écran de Windows Setup

Au lancement de Windows Setup, l’installateur demande des paramètres régionaux et linguistiques. Selon la version du média, la présentation exacte des écrans peut varier.

ParamètreRôle
LangueDétermine la langue utilisée pendant l’installation et, selon l’image, celle du système.
Format régionalInfluence notamment certains formats de date, heure et nombres.
ClavierDétermine la disposition utilisée pour la saisie.

Après vérification des paramètres, l’utilisateur poursuit vers l’installation de Windows.

Exercice 5. Pourquoi faut-il vérifier la disposition du clavier avant de saisir des mots de passe ou des informations de compte ?

6. Licence, clé de produit et édition

Windows Setup peut demander une clé de produit ou proposer de poursuivre selon le scénario de licence. Une clé de produit est un identifiant utilisé dans le processus d’activation de Windows.

Lorsque plusieurs éditions sont proposées par le média, il faut sélectionner celle qui correspond à la licence et au contexte prévu. Le choix d’une édition ne doit pas être effectué au hasard, car les fonctionnalités disponibles peuvent différer.

À distinguer : installer Windows et activer Windows sont deux opérations liées mais différentes. L’installation place et configure le système; l’activation vérifie ensuite l’état de licence.
Exercice 6. Expliquez la différence entre installation et activation de Windows.

7. Mise à niveau ou installation personnalisée

Windows Setup peut être utilisé dans différents scénarios. Deux notions doivent être distinguées.

TypePrincipeSituation
Mise à niveauLe programme d’installation met à niveau un système Windows existant en cherchant à conserver les éléments prévus par le scénario choisi.Migration depuis une installation Windows compatible.
Installation personnaliséeWindows est installé sur la partition choisie; ce scénario permet notamment de travailler sur la structure du disque pendant une nouvelle installation.Nouvelle installation, laboratoire, disque préparé ou réinstallation planifiée.
Attention : ne supprimez ou ne formatez jamais une partition simplement parce qu’elle apparaît dans la liste. Identifiez d’abord le disque, sa capacité, son contenu et les données à conserver.
Exercice 7. Vous devez installer Windows dans une nouvelle VM dont le disque virtuel est vide. Quel type d’installation est adapté ? Justifiez.

8. Choisir le disque et la partition cible

Cette étape est l’une des plus importantes. Windows Setup affiche les disques, partitions et espaces non alloués détectés. Le technicien doit reconnaître la destination prévue avant de poursuivre.

Espace non alloué

Un espace non alloué est une zone du disque qui n’appartient actuellement à aucune partition. Dans un laboratoire avec un disque virtuel neuf, Windows Setup peut créer les partitions nécessaires à partir de cet espace.

Partitions existantes

Sur une machine déjà utilisée, plusieurs partitions peuvent être présentes : partition système EFI, partition Windows, récupération ou partitions contenant d’autres données. Leur suppression peut rendre un système inutilisable ou provoquer une perte de données.

Scénario de laboratoire : une VM possède un seul disque virtuel neuf de 80 Go affiché comme espace non alloué. Après avoir confirmé qu’il s’agit bien du disque virtuel de la VM, cet espace peut être sélectionné comme destination de la nouvelle installation.

9. Ce que fait Windows Setup

Une fois les choix validés, Windows Setup prépare le stockage, applique l’image Windows, configure les informations de démarrage puis poursuit la configuration du système. L’ordinateur peut redémarrer plusieurs fois pendant ce processus.

Important : après le premier redémarrage, évitez de relancer accidentellement l’installation depuis le début. Dans une VM, l’hyperviseur peut gérer le média virtuel; sur une machine physique, le comportement dépend de l’ordre de démarrage et du support utilisé.

Pendant cette phase

  • ne pas éteindre brutalement la machine;
  • ne pas supprimer le disque virtuel ou déconnecter le stockage cible;
  • laisser Windows terminer les redémarrages nécessaires;
  • observer les messages plutôt que d’interrompre le processus.
Exercice 9. Pourquoi l’ordinateur redémarre-t-il pendant l’installation et pourquoi faut-il éviter de recommencer l’installation depuis le support après chaque redémarrage ?

10. OOBE — première configuration de Windows

Définition

OOBE signifie Out-of-Box Experience. Il s’agit de la série d’écrans de première configuration affichée après l’installation avant l’utilisation normale du bureau Windows.

Selon l’édition, la version, la connexion réseau et les politiques appliquées, l’ordre et la présence de certains écrans peuvent varier. Les étapes peuvent notamment concerner la région, le clavier, le réseau, les mises à jour, la licence, le compte, Windows Hello et les paramètres de confidentialité.

Approche pédagogique

Ne mémorisez pas uniquement l’ordre visuel des écrans : identifiez plutôt la fonction de chaque choix. Une nouvelle version de Windows peut modifier l’apparence ou l’ordre de l’OOBE sans changer les objectifs fondamentaux de configuration.

Exercice 10. Que signifie OOBE et à quel moment cette phase apparaît-elle ? Donnez trois catégories de paramètres qui peuvent y être configurées.

11. Réseau, compte et confidentialité

La configuration initiale peut demander une connexion réseau et proposer ou exiger certaines étapes de compte selon l’édition et le scénario. Évitez d’enseigner une méthode de contournement fondée sur un écran particulier : les exigences de Windows évoluent avec les versions.

Points à analyser

  • Réseau : vérifier que l’interface réseau est reconnue et que la connectivité correspond au laboratoire.
  • Compte : utiliser le type de compte prévu par les règles du cours ou de l’organisation.
  • Nom du poste : adopter une convention claire lorsqu’un nom est demandé ou configuré ensuite.
  • Confidentialité : lire les options proposées avant de les accepter ou de les désactiver.
  • Windows Hello : comprendre qu’il s’agit d’un mécanisme d’authentification proposé par Windows dans les scénarios compatibles.
Exercice 11. Pourquoi un technicien ne devrait-il pas simplement cliquer sur « Suivant » à chaque écran de confidentialité ou de compte sans lire les choix proposés ?

12. Première ouverture de session et vérifications

L’apparition du bureau ne signifie pas que le travail du technicien est terminé. Il faut vérifier l’état général du système avant de considérer l’installation comme valide.

VérificationObjectif
DémarrageConfirmer que Windows démarre normalement depuis le disque prévu.
Édition et activationVérifier l’édition installée et l’état d’activation selon le contexte de licence.
Gestionnaire de périphériquesRepérer les périphériques non reconnus ou nécessitant un pilote.
RéseauVérifier l’interface, l’adressage et la connectivité attendue.
Windows UpdateRechercher et appliquer les mises à jour nécessaires.
StockageVérifier les volumes, leur capacité et l’espace disponible.
Date, heure et régionConfirmer les paramètres essentiels du poste.

13. Pilotes et Windows Update

Un pilote est un logiciel permettant au système d’exploitation de communiquer correctement avec un périphérique. Windows peut installer automatiquement de nombreux pilotes, mais une vérification reste nécessaire.

Méthode

  1. Ouvrir le Gestionnaire de périphériques.
  2. Repérer les périphériques signalés comme non reconnus ou en erreur.
  3. Exécuter Windows Update.
  4. Lorsque nécessaire, utiliser les pilotes appropriés provenant d’une source fiable, idéalement du fabricant.
  5. Redémarrer si l’installation du pilote ou de la mise à jour le demande.
  6. Vérifier de nouveau le périphérique.
Dans une VM : l’hyperviseur peut proposer des outils ou pilotes invités améliorant l’affichage, la souris, le presse-papiers ou d’autres fonctions. Leur installation dépend de l’environnement de virtualisation utilisé.
Exercice 13. Après l’installation, l’affichage fonctionne uniquement avec une résolution limitée. Quelles vérifications effectueriez-vous avant de conclure à une panne matérielle ?

14. Vérifier les informations du système installé

Une validation simple consiste à vérifier que l’édition, la version, l’architecture et les principales ressources détectées correspondent au scénario prévu.

Exemples de vérifications

  • Paramètres → Système → Informations système : informations générales sur Windows et le matériel;
  • Gestionnaire de périphériques : état des périphériques;
  • Gestion des disques : structure du stockage;
  • Windows Update : état des mises à jour;
  • Paramètres réseau : connectivité et configuration de l’interface.

16. Manipulation guidée — installer Windows 11 dans une VM

Cette manipulation permet de pratiquer une installation complète dans un environnement contrôlé.

  1. Préparer la VM : vérifier la RAM, les vCPU, le disque virtuel et l’image ISO.
  2. Démarrer sur l’ISO : lancer la VM et vérifier que Windows Setup apparaît.
  3. Configurer la langue et le clavier : contrôler les paramètres avant de poursuivre.
  4. Démarrer l’installation : choisir les options correspondant au scénario du laboratoire.
  5. Sélectionner l’édition : uniquement si le média présente ce choix et selon les consignes de licence du laboratoire.
  6. Choisir l’installation personnalisée : dans le scénario d’une VM neuve.
  7. Identifier le disque virtuel : vérifier sa capacité avant toute action.
  8. Sélectionner l’espace prévu : utiliser le disque virtuel neuf prévu pour l’exercice.
  9. Laisser Windows Setup travailler : attendre la copie, l’application de l’image et les redémarrages.
  10. Effectuer l’OOBE : configurer les paramètres demandés selon les consignes du laboratoire.
  11. Atteindre le bureau : vérifier que Windows démarre normalement.
  12. Valider l’installation : contrôler périphériques, réseau, stockage, mises à jour et informations système.
Règle du laboratoire : toutes les opérations de suppression ou de formatage doivent être réalisées uniquement sur le disque virtuel prévu pour l’exercice. Sur une machine physique, une mauvaise sélection peut supprimer des données réelles.

Activité de synthèse

Construisez une procédure professionnelle d’installation de Windows 11 organisée en quatre phases :

  1. Avant l’installation : compatibilité, sauvegarde, ISO/support, stockage et paramètres de démarrage.
  2. Pendant Windows Setup : paramètres initiaux, type d’installation, disque cible et progression.
  3. Première configuration : OOBE, réseau, compte et confidentialité selon le scénario.
  4. Validation : pilotes, mises à jour, activation, réseau, stockage et informations système.

Pour chaque phase, indiquez au moins une erreur possible et une mesure permettant de la prévenir.

À retenir

Une installation de Windows ne consiste pas uniquement à copier des fichiers. Le technicien doit préparer le support et les données, démarrer sur le bon média, identifier sans ambiguïté le disque cible, suivre Windows Setup, terminer l’OOBE puis valider les pilotes, le réseau, le stockage, les mises à jour et l’état général du système. La vérification du disque et la sauvegarde des données restent essentielles avant toute opération destructive.
