    Leçon 25 · Linux

    Shell Linux et gestion des fichiers

    Découvrir le terminal, naviguer dans l’arborescence et gérer les fichiers et répertoires avec méthode.

    Objectifs pédagogiques

    À la fin de cette leçon, vous serez capable de distinguer terminal et shell, de reconnaître les dossiers Linux, d’utiliser des chemins absolus et relatifs, et de créer, consulter, copier, déplacer, renommer ou supprimer des fichiers de façon prudente.

    Sommaire

    01 — Comprendre Linux et le shell

    03 — Arborescence et répertoires essentiels
    04 — Chemins absolus et relatifs

    01Comprendre Linux et le shell

    Linux est un système d’exploitation utilisé sur les serveurs, dans le cloud, les réseaux et la cybersécurité. Il existe plusieurs distributions : Ubuntu, Debian, Fedora, Linux Mint et Kali Linux. Le terminal est une interface textuelle ; le shell (souvent Bash) interprète les commandes saisies.

    Exemples dans le terminal
    whoami
pwd
echo "Bonjour Linux"
    À retenir : Le terminal affiche les commandes et leurs résultats ; le shell les interprète. Une commande suit souvent la forme : commande [options] [arguments].

    02Interface graphique ou ligne de commande

    L’interface graphique permet d’agir avec des fenêtres et la souris. La ligne de commande facilite les opérations répétitives, l’automatisation et l’administration à distance.

    Exemples dans le terminal
    pwd
ls
    À retenir : Une commande peut être complétée par une option, par exemple ls -l, et un argument, par exemple cd Documents.

    03Arborescence et répertoires essentiels

    La racine / est le point de départ de l’arborescence. /home contient les dossiers personnels ; /etc les configurations ; /bin les commandes essentielles ; /usr les programmes ; /var les données variables ; /tmp les fichiers temporaires ; /boot les fichiers de démarrage ; /dev les périphériques ; /mnt et /media les points de montage ; /opt certains logiciels additionnels.

    Exemples dans le terminal
    ls /
ls /home
    À retenir : Travaillez de préférence dans votre dossier personnel plutôt que de modifier les dossiers système.

    04Chemins absolus et relatifs

    Un chemin absolu commence par / et part de la racine ; un chemin relatif dépend du dossier courant. Les symboles . (dossier courant), .. (parent) et ~ (dossier personnel) sont indispensables.

    Exemples dans le terminal
    cd ~
pwd
cd ..
cd /tmp
cd -
    À retenir : Exemple : /home/etudiant/Documents est absolu ; Documents et ../Images sont relatifs.

    05Se repérer et naviguer

    pwd affiche le chemin du dossier courant ; ls liste les éléments ; cd change de répertoire. Les options de ls permettent d’adapter l’affichage.

    Exemples dans le terminal
    pwd
ls
ls -l
ls -a
ls -lh
ls -la
cd ~
    À retenir : -l : détails ; -a : fichiers cachés ; -h : tailles lisibles (avec -l) ; cd - : dossier précédent.

    06Créer des dossiers et des fichiers

    mkdir crée un répertoire, mkdir -p crée les dossiers intermédiaires si nécessaire, et touch crée un fichier vide ou actualise sa date de modification.

    Exemples dans le terminal
    mkdir atelier
mkdir -p atelier/projets/linux
cd atelier
touch notes.txt
touch a.txt b.txt
ls -la
    À retenir : Vérifiez votre emplacement avec pwd avant toute création.

    07Copier, déplacer et renommer

    cp copie en conservant l’original ; mv déplace ou renomme selon la destination. Les options -r, -i et -v servent respectivement à copier récursivement, demander confirmation et afficher les opérations.

    Exemples dans le terminal
    cp notes.txt copie_notes.txt
mkdir sauvegardes
cp -i notes.txt sauvegardes/
cp -r sauvegardes sauvegardes_backup
mv copie_notes.txt notes_finales.txt
mv notes_finales.txt sauvegardes/
    À retenir : Attention : une copie ou un déplacement peut écraser un fichier existant. Préférez -i pendant les exercices.

    08Supprimer avec prudence

    rm supprime des fichiers ; rmdir supprime uniquement les répertoires vides ; rm -r supprime un dossier et son contenu. Une suppression avec rm ne passe généralement pas par la corbeille.

    Exemples dans le terminal
    touch a_supprimer.txt
rm -i a_supprimer.txt
mkdir dossier_vide
rmdir dossier_vide
# rm -r dossier : à éviter sans vérification
    À retenir : L’option -f force la suppression ; vérifiez toujours pwd et ls avant d’utiliser rm -r ou rm -f.

    09Lire le contenu d’un fichier

    cat affiche directement le contenu d’un fichier court ; less permet de parcourir un fichier long, avec les flèches ou la barre d’espace et la touche q pour quitter.

    Exemples dans le terminal
    echo "Ma première note Linux" > message.txt
cat message.txt
less message.txt
    À retenir : La redirection > remplace le contenu du fichier cible : utilisez-la avec précaution.

    10Manipulation guidée : organiser un projet

    Réalisez les commandes suivantes dans votre dossier personnel. Après chaque étape, vérifiez le résultat avec pwd ou ls.

    Scénario complet
    cd ~
mkdir linux_debut
cd linux_debut
touch notes.txt
ls -l
mv notes.txt introduction_linux.txt
mkdir exercices
mv introduction_linux.txt exercices/
ls
cd exercices
ls -l
cat introduction_linux.txt
    Résultat attendu : le fichier introduction_linux.txt se trouve dans le sous-dossier exercices. Comme il est vide, cat n’affiche aucun texte.

    11Exercices pratiques et synthèse

    Exercice 1 — Gestion d’un dossier

    1. Allez dans votre dossier personnel.
    2. Créez un dossier linux_tp1 et entrez dedans.
    3. Créez deux fichiers a.txt et b.txt.
    4. Créez un sous-dossier docs puis déplacez-y a.txt.
    5. Renommez b.txt en notes.txt.
    6. Affichez le contenu du dossier courant puis celui de docs.
    7. Supprimez notes.txt en demandant confirmation.

    Vérification : docs/a.txt doit exister et notes.txt ne doit plus être présent.

    Exercice 2 — Réflexion et commandes

    1. Expliquez la différence entre cp et mv, avec un exemple.
    2. Écrivez la commande pour créer cours/linux/tp en une seule étape.
    3. Vous êtes dans /home/etudiant/cours : donnez un chemin relatif vers /home/etudiant/images.
    4. Quelle différence existe entre ls -l, ls -a et ls -lh ?
    5. Pourquoi faut-il être prudent avec rm -r ?

    Synthèse

    Navigation : pwd, ls, cd · Création : mkdir, touch · Gestion : cp, mv, rm, rmdir · Lecture : cat, less.

    Bon réflexe : vérifier le répertoire courant, comprendre la commande, puis contrôler le résultat. Ne jamais lancer une suppression récursive sans savoir exactement ce qu’elle cible.
