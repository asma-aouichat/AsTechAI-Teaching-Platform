Leçon 13

Ligne de commande Windows

Comprendre CMD, sa syntaxe et ses commandes pour naviguer, manipuler des fichiers, consulter le système et vérifier chaque opération.

Objectifs d’apprentissage. À la fin de cette leçon, l’étudiant sera capable d’utiliser l’Invite de commandes Windows, de naviguer dans une arborescence, de manipuler des fichiers et dossiers, de consulter des informations système et réseau, d’utiliser les redirections et de vérifier rigoureusement le résultat de chaque commande.

1. Qu’est-ce que l’invite de commandes Windows ?

1.1 Définition

CMD signifie ici Command Prompt, appelé en français Invite de commandes. Il s’agit d’une interface textuelle de Windows dans laquelle l’utilisateur écrit des commandes au clavier.

Contrairement à une interface graphique, où l’on clique sur des fenêtres, boutons et menus, CMD permet de demander directement au système d’exécuter une opération à partir d’une instruction textuelle.

1.2 Pourquoi apprendre CMD ?

CMD permet notamment de naviguer dans les dossiers, créer ou manipuler des fichiers, consulter des informations système et réseau, lancer certains outils d’administration et automatiser des suites simples d’opérations.

Exemple : au lieu d’ouvrir l’Explorateur de fichiers pour créer un dossier, on peut saisir mkdir C:\TP_CMD.

1.3 Interface graphique ou ligne de commande ?

Les deux approches sont complémentaires. L’interface graphique facilite la découverte visuelle. La ligne de commande devient particulièrement utile lorsqu’une opération doit être répétée, documentée ou exécutée rapidement.

  1. Expliquez avec vos propres mots ce qu’est CMD.

2. Ouvrir CMD et comprendre l’invite

2.1 Ouvrir une invite normale

  1. Ouvrez Démarrer.
  2. Recherchez Invite de commandes ou cmd.
  3. Ouvrez l’application.

Une ligne semblable à C:\Users\Etudiant> apparaît. La partie avant > indique généralement le chemin courant, c’est-à-dire le dossier dans lequel CMD travaille actuellement.

2.2 Invite normale et invite administrateur

Certaines commandes fonctionnent avec les droits ordinaires de l’utilisateur. D’autres opérations qui modifient des éléments protégés du système peuvent nécessiter une invite ouverte avec des privilèges administratifs.

UAC signifie User Account Control, ou Contrôle de compte d’utilisateur. Windows peut afficher une demande de confirmation lorsqu’une opération nécessite une élévation de privilèges.

Règle : n’ouvrez pas systématiquement CMD en administrateur. Utilisez uniquement les privilèges nécessaires à la tâche.

Mini-exercice 2

  1. Ouvrez CMD dans la VM.
  2. Recopiez le chemin affiché avant le symbole >.
  3. Expliquez ce que représente ce chemin.

3. Comment apprendre une commande Windows ?

Pour chaque nouvelle commande, utilisez toujours la même méthode :

  1. Définition : à quoi sert la commande ?
  2. Syntaxe générale : comment la commande est-elle structurée ?
  3. Paramètres et options : quelles variantes peut-on demander ?
  4. Exemples : remplacer les éléments génériques par des valeurs réelles.
  5. Exécution : lancer la commande dans l’environnement de laboratoire.
  6. Vérification : confirmer que le résultat obtenu correspond au résultat attendu.
Exemple de syntaxe générique :
commande <source> <destination> [option]

<source> et <destination> sont des valeurs à remplacer. Les crochets signalent ici un élément facultatif dans la représentation pédagogique de la syntaxe.

Aide intégrée

Avant de mémoriser une option, consultez l’aide disponible sur le poste. Selon la commande, utilisez notamment :

help help <commande> <commande> /?
Exemple : dir /? affiche l’aide de dir et les options prises en charge par la version de Windows utilisée.

Mini-exercice 3

  1. Exécutez help.
  2. Exécutez dir /?.
  3. Choisissez une option affichée par l’aide et expliquez son rôle sans encore l’exécuter.

4. Navigation : dir et cd

4.1 dir — afficher le contenu d’un dossier

Définition : dir affiche les fichiers et sous-dossiers d’un emplacement.

Syntaxe générale

dir [chemin] [options]

Options utiles

OptionRôleExemple
/pAfficher page par pagedir /p
/wAfficher une liste large et compactedir /w
/aAfficher selon les attributs; sans attribut précisé, inclure notamment les éléments masqués et systèmedir /a

4.2 cd — changer de dossier courant

Définition : cd, pour change directory, permet d’afficher ou de modifier le dossier courant.

Syntaxe générale

cd [chemin] cd .. cd \\ cd /d <lecteur:\chemin>

.. représente le dossier parent. \\ ramène à la racine du lecteur courant. L’option /d permet aussi de changer de lecteur lorsque le chemin cible se trouve sur un autre lecteur.

Exemple guidé :
cd /d C:\\ dir cd Users dir cd .. cd \\

5. Créer et supprimer des dossiers : mkdir et rmdir

5.1 mkdir

Définition : mkdir crée un ou plusieurs dossiers. La forme courte md est également disponible.

mkdir <dossier>
Exemple :
mkdir C:\TP_CMD mkdir C:\TP_CMD\Documents

5.2 rmdir

Définition : rmdir supprime un dossier. La forme courte est rd.

rmdir <dossier> [options]
OptionRôle
/sSupprimer l’arborescence du dossier, y compris son contenu.
/qMode silencieux avec /s, sans demande de confirmation.
Attention : rmdir /s /q peut supprimer une arborescence sans confirmation. Utilisez-le uniquement dans le dossier de laboratoire après avoir vérifié le chemin.

Mini-exercice 5

  2. Utilisez dir pour vérifier leur création.
  3. Créez un dossier temporaire, vérifiez-le puis supprimez-le avec rmdir.

6. Copier, déplacer et renommer : copy, move et ren

6.1 copy

Définition : copy copie un ou plusieurs fichiers vers un autre emplacement.

copy <source> <destination>

Exemple : copy C:\TP_CMD\note.txt C:\TP_CMD\Sauvegarde\\

6.2 move

Définition : move déplace un fichier ou un dossier vers un autre emplacement.

move <source> <destination>

6.3 ren

Définition : ren ou rename modifie le nom d’un fichier ou d’un dossier.

ren <ancien_nom> <nouveau_nom>
Exemple progressif :
copy note.txt Sauvegarde\\ ren note.txt rapport.txt move rapport.txt Travail\\ dir Travail

7. Supprimer des fichiers : del

Définition : del supprime un ou plusieurs fichiers. Cette commande agit sur les fichiers, tandis que rmdir est utilisée pour les dossiers.

Syntaxe générale

del <fichier> [options]

Options utiles

OptionRôle
/pDemander une confirmation avant de supprimer chaque fichier.
/qNe pas demander de confirmation lors de certaines suppressions utilisant des caractères génériques.
Précaution : avant une suppression, utilisez dir pour vérifier le chemin et le nom du fichier ciblé.

Mini-exercice 7

  2. Vérifiez sa présence avec dir.
  3. Supprimez-le avec del /p.
  4. Utilisez de nouveau dir pour confirmer le résultat.

8. Afficher et créer du contenu simple : type et echo

8.1 type

Définition : type affiche dans CMD le contenu d’un fichier texte.

type <fichier>

8.2 echo

Définition : echo affiche un texte dans la console. Combiné à une redirection, il peut écrire du texte dans un fichier.

echo <texte>
Exemple :
echo Premier test CMD echo Premier test CMD > journal.txt type journal.txt

9. Redirections : > et >>

Définition : une redirection envoie la sortie d’une commande vers un fichier au lieu de l’afficher uniquement dans la console.

SymboleRôleExemple
>Écrire la sortie dans un fichier; le contenu existant est remplacé.dir > liste.txt
>>Ajouter la sortie à la fin du fichier.ipconfig >> journal.txt
Pourquoi est-ce utile ? Un technicien peut conserver le résultat d’une commande avant et après une modification afin de documenter son intervention.

10. Le pipe |

Définition : le pipe transmet la sortie d’une commande à une autre commande qui l’utilise comme entrée.

Syntaxe générale

commande1 | commande2

Une utilisation fréquente consiste à filtrer une sortie avec find ou findstr.

Exemple :
ipconfig | findstr "IPv4"

La première commande produit des informations réseau; findstr conserve les lignes contenant le texte recherché.

Mini-exercice 10

  1. Exécutez ipconfig.
  2. Exécutez ensuite ipconfig | findstr "IPv4".
  3. Comparez les deux sorties et expliquez le rôle du pipe.

11. Informations système : hostname, whoami et systeminfo

Ces commandes permettent d’identifier rapidement la machine, l’identité courante ou des informations sur Windows.

CommandeRôle
hostnameAfficher le nom de l’ordinateur.
whoamiAfficher l’identité du compte sous lequel la commande est exécutée.
systeminfoAfficher un ensemble d’informations sur le système Windows.
Réflexe de diagnostic : avant de modifier une machine, commencez par identifier sur quel ordinateur et avec quel compte vous travaillez.

12. Informations réseau : ipconfig, ping et nslookup

12.1 ipconfig

Définition : ipconfig affiche la configuration IP des interfaces réseau Windows.

ipconfig ipconfig /all

/all affiche des informations plus détaillées sur la configuration.

12.2 ping

Définition : ping envoie des messages de test à une destination IP ou à un nom d’hôte afin d’observer si des réponses reviennent. L’absence de réponse ne prouve toutefois pas à elle seule qu’une machine est hors ligne, car le trafic peut être filtré.

ping <destination>

12.3 nslookup

Définition : nslookup permet d’interroger le service de résolution de noms DNS afin d’obtenir des informations associées à un nom ou à une adresse.

nslookup <nom>

13. Réutiliser les commandes d’administration

Les commandes étudiées précédemment peuvent être exécutées depuis une invite disposant des privilèges nécessaires. Dans cette leçon, l’objectif est surtout de les intégrer à une démarche de ligne de commande.

CommandeObjet administréExemple de consultation
net userComptes utilisateursnet user
net localgroupGroupes locauxnet localgroup
icaclsPermissions de fichiers et dossiers NTFSicacls C:\TP_CMD

NTFS est un système de fichiers utilisé par Windows. Une ACL, ou liste de contrôle d’accès, décrit les autorisations associées à des identités sur une ressource.

Précaution : les modifications de comptes et de permissions doivent être réalisées uniquement sur les objets de laboratoire prévus pour le TP.

14. Construire un journal de diagnostic

Une ligne de commande devient particulièrement utile lorsque les résultats sont conservés dans un fichier. On peut ainsi constituer un petit journal technique.

echo === IDENTITE === > diagnostic.txt whoami >> diagnostic.txt echo === MACHINE === >> diagnostic.txt hostname >> diagnostic.txt echo === RESEAU === >> diagnostic.txt ipconfig >> diagnostic.txt type diagnostic.txt

Explication : la première ligne crée ou remplace le fichier. Les commandes suivantes ajoutent leurs résultats grâce à >>. La dernière commande affiche le journal.

  3. Ajoutez une quatrième information de votre choix.

15. Exemple intégrateur — préparer un espace de travail depuis CMD

Situation : un technicien doit préparer un dossier de test, conserver des informations sur la machine et produire une copie de sauvegarde du journal.

cd /d C:\\ mkdir TP_CMD cd TP_CMD mkdir Travail mkdir Sauvegarde echo === DIAGNOSTIC === > Travail\journal.txt whoami >> Travail\journal.txt hostname >> Travail\journal.txt ipconfig >> Travail\journal.txt type Travail\journal.txt copy Travail\journal.txt Sauvegarde\\ dir Travail dir Sauvegarde
Méthode à retenir : observer → planifier → exécuter → vérifier → tester → documenter.

Mini-exercice 15

Reproduisez le scénario dans la VM, puis adaptez-le : changez le nom du dossier principal, ajoutez une information système supplémentaire au journal et démontrez avec dir que la copie de sauvegarde existe.

À retenir

CMD est une interface textuelle de Windows. Une utilisation rigoureuse repose sur la compréhension du chemin courant, la syntaxe des commandes, leurs options et surtout la vérification des résultats. Le technicien doit être capable d’expliquer ce qu’il fait, de choisir la commande adaptée et de documenter son intervention.
